# non-METR distributor

[role](https://isotc204.org/iso14812/terms/role/) that is responsible for distributing [rules](rule.md) in manners that do not conform to METR

Clause: 3.3.1.17

EXAMPLE: distribution system that provides rules using protocols that do not meet METR security requirements

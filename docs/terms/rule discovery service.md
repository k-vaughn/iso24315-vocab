# rule discovery service

ITS service where one or more [METR user systems](METR user system.md) enhance the accuracy of the [METR distribution system](METR distribution system.md) by reporting [rules](rule.md) observed in the field

<object type="image/svg+xml" data="../../diagrams/rule discovery service.dot.svg">
    <img alt="rule discovery service Diagram" src="../../diagrams/rule discovery service.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.3.3.1

Note 1 to entry: The data can be sent through and summarized by an intermediary, such as a vehicle manufacturer.

Note 2 to entry: The reported rules can be used as the initial source for data.

Note 3 to entry: The reported rules can be used to update [METR](METR.md) to reflect real-time changes, such as due to natural disasters.

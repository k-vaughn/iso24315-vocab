# METR information

Any information provided by a [METR distribution system](METR distribution system.md) to a [METR consumer system](METR consumer system.md)

</object>

Clause: 3.2.1.10

## Specializations of METR information

| Class | Description |
| --- | --- |
| [fresh METR information](fresh METR information.md) | [METR information](METR information.md) that has a [freshness period](freshness period.md) that has not expired |
| [freshness period](freshness period.md) | duration during which an element of [METR information](METR information.md) is considered accurate |
| [localized distribution](localized distribution.md) | dissemination of [METR information](METR information.md) using wireless technologies with less than a 1-kilometer range |
| [outdated METR information](outdated METR information.md) | [METR information](METR information.md) that has a [freshness period](freshness period.md) that has expired |
| [pulled distribution](pulled distribution.md) | dissemination of [METR information](METR information.md) to a user based on a request or subscription |
| [pushed distribution](pushed distribution.md) | dissemination of [METR information](METR information.md) to a user based on general user registration or as a broadcast to all users within range |
| [wide-area distribution](wide-area distribution.md) | dissemination of [METR information](METR information.md) using wireless technologies with a range of greater than 1 kilometre |

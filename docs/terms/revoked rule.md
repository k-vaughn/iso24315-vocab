# revoked rule

[rule](rule.md) that has been retroactively designated as never being legally enforceable

<object type="image/svg+xml" data="../../diagrams/revoked rule.dot.svg">
    <img alt="revoked rule Diagram" src="../../diagrams/revoked rule.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.4.9

EXAMPLE: An electronic no parking rule might be revoked if it is discovered that the electronic version incorrectly identified the applicable times to be 03:00 to 20:00 when the actual rule identifies the applicable times to be 08:00 to 20:00.

Note 1 to entry: A rule that is revoked indicates that the rule should have never been enacted.

Note 2 to entry: There can be a period of time after a rule is revoked during which associated [conventional traffic control devices](conventional traffic control device.md) are still present.

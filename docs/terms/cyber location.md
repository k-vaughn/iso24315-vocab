# cyber location

set of one or more parameters that allow an electronic resource to be accessed in a secure manner through indicated communication mechanisms

Clause: 3.2.11.1

Example 1: A universal resource locator (URL) with a public key

Example 2: A radio frequency and protocol details used for broadcasting information and authentication credentials

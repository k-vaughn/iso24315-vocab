# supporting data provider

data [provider](crowd-sourced data provider.md) that is responsible for distributing [supporting data](supporting data.md) to [METR users](METR user.md) via interpreters (3.3.1.14)

Clause: 3.3.1.27

Note 1 to entry: Derived from SP-75.

Note 2 to entry: Supporting data providers include in-vehicle data providers and external data providers.

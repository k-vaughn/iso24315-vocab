# infrastructure-sourced data

[supporting data](supporting data.md) from an external source that has a fixed or portable location, including Internet servers

<object type="image/svg+xml" data="../../diagrams/infrastructure-sourced data.dot.svg">
    <img alt="infrastructure-sourced data Diagram" src="../../diagrams/infrastructure-sourced data.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.1.7

Example 1: current speed limit for a variable speed limit system as transmitted by a central or roadside system

Example 2: time of dusk as reported by a source from the Internet

Example 3: data reported from roadside sensors (authorized or not)

Note 1 to entry: Infrastructure-sourced data can be [jurisdiction-sourced](jurisdiction-sourced data.md) or [crowd-sourced](crowd-sourced data.md).

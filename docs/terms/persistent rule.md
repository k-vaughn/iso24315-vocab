# persistent rule

[rule](rule.md) that does not have any expectation of a [termination time](termination time.md)

Clause: 3.2.8.1

Note 1 to entry: Derived from SP-66,SP-133.

Note 2 to entry: A [variable rule](variable rule.md), such as a variable speed limit, often consists of a persistent rule (e.g., a variable speed limit applies to a specified stretch of a road) that is supplemented with [supporting data](supporting data.md) that identifies the current speed limit in effect.

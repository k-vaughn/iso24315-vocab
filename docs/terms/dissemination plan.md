# dissemination plan

plan for providing data to user systems

Clause: 3.2.11.2

Note 1 to entry: A dissemination plan includes identification of the data covered by the plan, the mode of delivery (e.g., via a centralized distribution system, local beacons, RSS feed, etc.) and the geographic area for dissemination.

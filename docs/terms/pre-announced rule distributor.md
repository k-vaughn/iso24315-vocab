# pre-announced rule distributor

[distributor](distributor.md) that is responsible for distributing all [pre-announced rules](pre-announced rule.md) requested by a [METR user](METR user.md) and within the publicized [data categories](data category.md) supported by the distributor

</object>

Clause: 3.3.1.19

Note 1 to entry: The pre-announced rule distributor is primarily envisioned to use a central system, but can use a mobile unit dispatched to a location without internet connectivity.

Note 2 to entry: A pre-announced rule distributor can also distribute [emergent rules](emergent rule.md) but does not bear the responsibility for doing so.

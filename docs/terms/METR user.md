# METR user

[role](https://isotc204.org/iso14812/terms/role/) that is responsible for using applicable [rules](rule.md) to fulfil a [need](https://isotc204.org/iso14812/terms/user need/)

<object type="image/svg+xml" data="../../diagrams/METR user.dot.svg">
    <img alt="METR user Diagram" src="../../diagrams/METR user.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.3.1.16

Admitted term: user

Note 1 to entry: METR users include [transport users](https://isotc204.org/iso14812/terms/transport user/) and [ancillary users](ancillary user.md).

Note 2 to entry: The need being fulfilled is often the performance of the dynamic driving task or similar action (e.g., the task of walking in a safe manner that complies with local rules) but can also be trip planning, rule verification, etc.

## Specializations of METR user

| Class | Description |
| --- | --- |
| [ancillary user](ancillary user.md) | [METR user](METR user.md) that is not a [transport-related user](transport-related user.md) |
| [transport-related user](transport-related user.md) | [METR user](METR user.md) that is either a [transport user](https://isotc204.org/iso14812/terms/transport user/), a [driver](https://isotc204.org/iso14812/terms/driver/), a [driving automation system](https://isotc204.org/iso14812/terms/driving automation system/), or a driver information system |

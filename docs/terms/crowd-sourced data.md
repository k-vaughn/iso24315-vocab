# crowd-sourced data

[supporting data](supporting data.md) from multiple external sources that are not signed by any [jurisdictional entity](jurisdictional entity.md) associated with the current location

<object type="image/svg+xml" data="../../diagrams/crowd-sourced data.dot.svg">
    <img alt="crowd-sourced data Diagram" src="../../diagrams/crowd-sourced data.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.1.2

Example 1: ice detected by multiple sources that are not signed by the local [jurisdictional entity](jurisdictional entity.md)

Example 2: data reported from sensors near the roadside but not signed by the local [jurisdictional entity](jurisdictional entity.md)

Note 1 to entry: Crowd-sourced data can include any combination of [infrastructure-sourced](infrastructure-sourced data.md) and [peer-sourced](peer-sourced data.md) data.

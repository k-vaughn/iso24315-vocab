# peer-sourced data

[supporting data](supporting data.md) from an external source that is designed to operate when mobile

Clause: 3.2.1.11

Example 1: notice from an emergency vehicle that it is responding to a call

Example 2: ice detected by another vehicle

Note 1 to entry: Peer-sourced data can be [crowd-sourced](crowd-sourced data.md) or [jurisdiction-sourced](jurisdiction-sourced data.md).

# rule

information regarding allowed or recommended behaviour as established by a [rule maker](rule maker.md) for its [jurisdictional area](jurisdictional area.md)

<object type="image/svg+xml" data="../../diagrams/rule.dot.svg">
    <img alt="rule Diagram" src="../../diagrams/rule.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.1.13

Note 1 to entry: Derived from SP-54.

Note 2 to entry: The jurisdictional area can be a [campus](campus.md).

Note 3 to entry: The primary focus of [METR](METR.md) is to provide rules that relate to transport users.

Note 4 to entry: Rules include [rules of the road](rules of the road.md), [regulations](regulation.md), [advisories](advisory.md), and [guidance](guidance.md).

| [observable rule](observable rule.md) | [rule](rule.md) that is [posted](posted rule.md) and able to be perceived by those affected |
| [overridden rule](overridden rule.md) | [rule](rule.md) that is enacted (3.2.4.3) but temporarily nullified or replaced |
| [persistent rule](persistent rule.md) | [rule](rule.md) that does not have any expectation of a [termination time](termination time.md) |
| [physical rule](physical rule.md) | representation of a [rule](rule.md) as presented in the field |
| [posted rule](posted rule.md) | [rule](rule.md) that is [publicized](publicized rule.md) to the those affected using [conventional traffic control devices](conventional traffic control device.md) |
| [pre-announced rule](pre-announced rule.md) | [METR rule](METR rule.md) distributed through the normal periodic update mechanism |
| [proposed rule](proposed rule.md) | [rule](rule.md) that is not yet approved by the [rule maker](rule maker.md) |

| [publicized rule](publicized rule.md) | [rule](rule.md) that is announced to the public |
| [regulation](regulation.md) | [rule](rule.md) having the force of law that is established by a [regulator](regulator.md) |
| [relevant rule](relevant rule.md) | [rule](rule.md) applicable to the [METR user](METR user.md) within present circumstances |
| [rescinded rule](rescinded rule.md) | [rule](rule.md) that has a [termination time](termination time.md) in the past |
| [revoked rule](revoked rule.md) | [rule](rule.md) that has been retroactively designated as never being legally enforceable |
| [rule order](rule order.md) | legally recognized document that officially specifies one or more [rules](rule.md) |
| [rule set](rule set.md) | aggregation of [rules](rule.md) coupled with shared meta-data |

| [temporary rule](temporary rule.md) | [rule](rule.md) that has or is expected to have a specified [termination time](termination time.md) |
| [termination time](termination time.md) | point in time at which a [rule](rule.md) became or is expected to become unenforceable |
| [time-based rule](time-based rule.md) | [condition-based rule](condition-based rule.md) where at least one condition is dependent on time |
| [unobservable rule](unobservable rule.md) | [rule](rule.md) that is [posted](posted rule.md) but not able to be perceived by a significant portion of those affected |
| [unposted rule](unposted rule.md) | [rule](rule.md) that is [publicized](publicized rule.md) to those affected primarily through means other than [conventional traffic control devices](conventional traffic control device.md) |
| [variable rule](variable rule.md) | [rule](rule.md) that contains a parameter whose value is dependent upon supporting data (3.2.1.12) issued by a [rule maker](rule maker.md) |

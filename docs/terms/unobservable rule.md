# unobservable rule

[rule](rule.md) that is [posted](posted rule.md) but not able to be perceived by a significant portion of those affected

Clause: 3.2.3.5

Note 1 to entry: Unobservable rules have been posted but might not be perceived properly due to any number of reasons, such as damage, fading, snow accumulation, obstructions, graffiti, removal, etc.

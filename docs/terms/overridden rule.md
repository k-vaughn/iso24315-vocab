# overridden rule

[rule](rule.md) that is enacted (3.2.4.3) but temporarily nullified or replaced

<object type="image/svg+xml" data="../../diagrams/overridden rule.dot.svg">
    <img alt="overridden rule Diagram" src="../../diagrams/overridden rule.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.4.6

Note 1 to entry: It is expected that an override will eventually terminate, even if the expected [termination time](termination time.md) is unknown.

Note 2 to entry: The item that is temporarily nullified is termed to be “overridden” and the item that it is replaced with is termed to be “overriding”.

Note 3 to entry: The replacement can be null.

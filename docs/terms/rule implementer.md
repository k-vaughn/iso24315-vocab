# rule implementer

[role](https://isotc204.org/iso14812/terms/role/) that is responsible for enabling a [rule](rule.md)

<object type="image/svg+xml" data="../../diagrams/rule implementer.dot.svg">
    <img alt="rule implementer Diagram" src="../../diagrams/rule implementer.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.3.1.22

Alternative preferred term: implementer

Note 1 to entry: Enabling the rule includes ensuring [unposted rules](unposted rule.md) are properly captured within the public [record](pubic record.md) and [posted rules](posted rule.md) are installed and [observable](observable rule.md).

Note 2 to entry: The rule implementer is responsible for notifying the associated [translator](translator.md) when [conventional traffic control devices](conventional traffic control device.md) have been implemented so that electronic records can be updated.

## Specializations of rule implementer

| Class | Description |
| --- | --- |
| [authorized actor](authorized actor.md) | [rule implementer](rule implementer.md) that has received permission from a rule maker (3.3.1.24) to enable and disable specific [rules](rule.md) as necessary |

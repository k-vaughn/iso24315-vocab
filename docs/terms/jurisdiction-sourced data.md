# jurisdiction-sourced data

[supporting data](supporting data.md) from an external source and that is signed by a [jurisdictional entity](jurisdictional entity.md) associated with the current location

    <img alt="jurisdiction-sourced data Diagram" src="../../diagrams/jurisdiction-sourced data.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.1.8

Example 1: current speed limit for a variable speed limit system

Example 2: notice from an emergency vehicle that it is responding to a call

Example 3: data reported from authorized roadside sensors

Note 1 to entry: Jurisdiction-sourced data can be [infrastructure-sourced](infrastructure-sourced data.md) or [peer-sourced](peer-sourced data.md).

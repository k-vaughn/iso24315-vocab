# variable rule

[rule](rule.md) that contains a parameter whose value is dependent upon supporting data (3.2.1.12) issued by a [rule maker](rule maker.md)

<object type="image/svg+xml" data="../../diagrams/variable rule.dot.svg">
    <img alt="variable rule Diagram" src="../../diagrams/variable rule.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.9.3

Example 1: A speed limit that changes based on RLA decisions

Example 2: A traffic signal, which changes states as determined by a traffic signal controller

Note 1 to entry: The supporting data can be generated by an automated system under the authority of the RLA.

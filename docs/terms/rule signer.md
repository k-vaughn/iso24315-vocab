# rule signer

[role](https://isotc204.org/iso14812/terms/role/) that reviews and formally confirms the accuracy and integrity of an [electronic rule](electronic rule.md)

</object>

Clause: 3.3.1.24

Note 1 to entry: Derived from SP-41,SP-158.

Note 2 to entry: METR uses non-repudiation to permanently associate the rule signing organization with the electronic rule (e.g., using an electronic signature). This can result in the assignment of legal responsibility for the accuracy and integrity of the rule. The association to the specific responsible individual can be achieved through in a multi-step process. For example, the [METR regulation system](METR regulation system.md) can associate the individual rule signing agent to the rule via an internal database entry while the electronic rule is associated with a rule signing organization through the use of an electronic signature.

Note 3 to entry: Ideally, the rule signing organization is the rule making organization but it can be a separate entity (e.g., if the rule making organization does not provide electronic rules).

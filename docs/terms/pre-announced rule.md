# pre-announced rule

[METR rule](METR rule.md) distributed through the normal periodic update mechanism

</object>

Clause: 3.2.7.2

Note 1 to entry: Derived from SP-133.

Note 2 to entry: Pre-announced rules do not require low-latency communications because they are distributed well enough in advance so that all users with up-to-date [rule sets](rule set.md) will have a copy of the rule.

Note 3 to entry: Pre-announced rules typically have relatively long [freshness periods](freshness period.md) but can be impacted by [emergent rules](emergent rule.md).

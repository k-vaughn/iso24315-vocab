# installer

[role](https://isotc204.org/iso14812/terms/role/) that is responsible for posting [rules](rule.md) for a [jurisdictional area](jurisdictional area.md) using [conventional traffic control devices](conventional traffic control device.md)

</object>

Clause: 3.3.1.14

Note 1 to entry: Installer responsibilities include installing signs, signals, markings, physical barriers, etc. to properly reflect the rules established by the [rule maker](rule maker.md).

Note 2 to entry: The installer can leave the conventional traffic control device in an [unobservable](unobservable rule.md) state (e.g., the conventional traffic control device can be covered or in the case of a message sign left blank). In this case, a separate [rule implementer](rule implementer.md) can be made responsible for implementing the rule (e.g., removing a cover or posting a message on a sign). Alternatively, a single entity can serve as both the installer and rule implementer.

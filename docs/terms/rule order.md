# rule order

legally recognized document that officially specifies one or more [rules](rule.md)

<object type="image/svg+xml" data="../../diagrams/rule order.dot.svg">
    <img alt="rule order Diagram" src="../../diagrams/rule order.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.1.14

Admitted term: traffic regulation order

Note 1 to entry: A rule order can be associated with meta-data that activates or de-activates all rules defined within the order. For example, a [rule maker](rule maker.md) can define an order containing multiple rules that can be made [active](active rule.md) or [inactive](inactive rule.md) as a single unit.

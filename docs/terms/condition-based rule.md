# condition-based rule

[rule](rule.md) that becomes [active](active rule.md) based on explicitly stated conditions

<object type="image/svg+xml" data="../../diagrams/condition-based rule.dot.svg">
    <img alt="condition-based rule Diagram" src="../../diagrams/condition-based rule.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.9.1

Example 1: “when workers present”

Example 2: “dusk”

Example 3: "08:00 - 12:00"

Note 1 to entry: Condition-based rules can be based on multiple conditions.

Note 2 to entry: Time-based rules (e.g., a parking rule that is only in effect during certain hours) are one type of condition-based rules.

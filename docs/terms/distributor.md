# distributor

[role](https://isotc204.org/iso14812/terms/role/) that is responsible for gathering [rules](rule.md) from one or more [translators](translator.md) and distributing them to [METR users](METR user.md) via [receivers](receiver.md) and [adapters](adapter.md)

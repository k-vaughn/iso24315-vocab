# system of systems

set of operationally and managerially independent systems that interoperate for a period of time to achieve one or more stated purposes

</object>

Clause: 3.3.2.12

Note 1 to entry: The operational and managerial independence of each component system complicates the operation and management of these systems. For example, the systems within a system of systems are upgraded and maintained on different schedules and the design of the system of systems is more complex as a result.

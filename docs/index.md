# METR Vocabulary

The management of electronic transport regulations (METR) provides a means for METR users to obtain trustworthy, authoritative, machine-interpretable, publicly available, transport-related information for the use of the road network to better provide safe, efficient, sustainable, comfortable, and equitable transport services. The scope of METR includes both rules that are relatively static (e.g., static speed limits) as well as those that are dynamic (e.g., variable speed limits, signalized intersections). However, where appropriate, METR incorporates existing standards (e.g., ISO/TS 19091 for signalized intersections). This document defines terms specific to the ISO 24315 series. The formal ontology is maintained through a [GitHub project](https://github.com/ISO-TC204/iso24315-vocab).


The formal definition of the terms is available in [TTL Syntax](metrVocabulary.ttl).

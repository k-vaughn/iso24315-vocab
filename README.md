# ISO 24315 _Intelligent Transport Systems — Management of electronic transport regulations (METR) — Vocabulary_

The public website for this vocabulary is intended to be published at [https://isotc204.org/iso24315-vocab](https://isotc204.org/iso24315-vocab).

This repository is provided to promote the collaborative development of terminology for the Management of Electronic Transport Regulations (METR) community. The work is led by ISO/TC 204, but we are interested in receiving input from the full ITS community so that the end result is a resource that will be widely used and accepted. Terms given in ISO 14812 and ISO/IEC/IEEE 24765 also apply.

The contents of this vocabulary are periodically standardized in the ISO 24315 series, whereas this GitHub project is used for maintenance and adding new terms as well as a history of changes.

The process used by this effort conforms to ISO 704:2009, which defines the following process for each concept (i.e., meaning of a term) that you wish to define:

1. Analyse the intension (i.e., characteristics) and extension (i.e., resulting set of objects) of the concept
2. Determine the concept's relationships to other concepts
3. Illustrate the relationships with a concept diagram
4. Formulate definitions based on the relationships
5. Assign a designation (i.e., the term) to each concept in the diagram

The process used by this effort also conforms to ISO 24156-1:2014, which defines how to use UML to illustrate relationships with a concept diagram (Step 3 above).
